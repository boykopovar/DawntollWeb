# Dawntoll

Dawntoll («До́нтол») — браузерная 3D-игра о выживании на железной дороге. Игровой цикл включает обустройство временной базы, сбор ресурсов, оборону от зомби и ремонт поезда. Отправление - на рассвете.

## Технологии

C#, .NET 10, ASP.NET Core, Blazor Web App, Razor Components. Текущий режим интерактивности — Interactive Server. Клиентский 3D-рендеринг запланирован.
